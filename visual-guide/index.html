1The idea in 60 secondsFikir: 60 saniyede

Every character Copilot reads costs tokens. Comments, blank lines, repeated log lines and even secrets are paid for and sent to the model. This project sits between the agent and your files:

Copilot'ın okuduğu her karakter token harcar. Yorumlar, boş satırlar, tekrar eden log satırları ve hatta gizli anahtarlar da ücretlendirilir ve modele gönderilir. Bu proje, agent ile dosyalarınız arasına girer:

With itAraçla Your fileDosyanız→ read_file_optimized (MCP)→ ✂ prunebuda→ 🛡 mask secretssırları maskele→ LLM gets 985 tokensLLM 985 token alır
The tool only works when the model chooses to call itAraç yalnızca model onu çağırmayı seçtiğinde çalışır That is why the repo ships .github/copilot-instructions.md and why each tool description says “use me instead of the built-in file reader”. VS Code has no API to rewrite Copilot's own prompt, so optimization happens only at the tool-output boundary. Bu yüzden repoda .github/copilot-instructions.md bulunur ve her araç açıklaması “yerleşik dosya okuyucu yerine beni kullan” der. VS Code, Copilot'ın kendi prompt'unu yeniden yazmak için bir API sunmaz; bu nedenle optimizasyon yalnızca araç çıktısı sınırında gerçekleşir.

2Architecture: two processes, one shared fileMimari: iki süreç, bir ortak dosya

The extension and the MCP server are different programs. They never call each other directly: VS Code starts the server, Copilot talks to it through VS Code, and the only thing both sides share is a small JSON file.

Eklenti ve MCP sunucusu farklı programlardır. Birbirlerini doğrudan çağırmazlar: sunucuyu VS Code başlatır, Copilot ona VS Code üzerinden konuşur ve iki tarafın tek ortak noktası küçük bir JSON dosyasıdır.

Good to know: how the optimizer stays safeBilmekte fayda var: optimizer güvenli kalmak için ne yapar
  • Only comments that occupy whole lines are removed. A comment that shares a line with code, or comment-like text inside a string (for example the glob "src/**/*.ts"), is left alone: telling them apart would need a real parser, and guessing wrong deletes code.
  • Repeated lines are folded only for log and plaintext. Code and data (arrays, tables, markup) can repeat a line legitimately, so they are never folded. Pass languageId: 'log' to optimize_context for logs and terminal output.
  • With no languageId, text that merely looks like Markdown (any line starting with # , - or > ) is not pruned at all, only redacted.
  • Yalnızca bütün satırı kaplayan yorumlar silinir. Kodla aynı satırı paylaşan bir yorum ya da bir string içindeki yorum benzeri metin (örneğin "src/**/*.ts" glob'u) olduğu gibi bırakılır: ikisini ayırmak gerçek bir ayrıştırıcı (parser) gerektirir ve yanlış tahmin kodu siler.
  • Tekrar eden satırlar yalnızca log ve plaintext için katlanır. Kod ve veri (diziler, tablolar, işaretleme) bir satırı meşru olarak tekrarlayabilir; bu yüzden asla katlanmaz. Loglar ve terminal çıktıları için optimize_context'e languageId: 'log' verin.
  • languageId verilmezse yalnızca Markdown'a benzeyen metin (# , - veya > ile başlayan herhangi bir satır) hiç budanmaz, yalnızca maskelenir.

Returns the optimized text, preceded by a one-line summary when anything changed.Verdiğiniz her metni (log, terminal çıktısı, API yanıtı) optimize eder.
