Enterprise AI Token Optimizer

LLM'e ulaşmadan önce bağlamı budayan MCP tabanlı VS Code eklentisi

v0.0.10 · MIT · TypeScript · Model Context Protocol

Problem

  • Copilot/agent araçları dosya ve metin içeriklerini olduğu gibi modele gönderir.
  • Yorumlar, fazla boşluklar ve tekrar eden satırlar gereksiz token tüketir.
  • Daha fazla token: daha yüksek maliyet, daha yavaş yanıt, dolan context penceresi.
  • Kazanılan tasarrufu ölçecek şeffaf bir yöntem yok.

Çözüm

  • Eklenti, bir MCP sunucusu kaydeder; agent bu araçları ek yapılandırma olmadan kullanır.
  • İçerik, modele gitmeden önce optimize() motorundan geçer.
  • Kazanım tiktoken (o200k_base) ile gerçek token sayısı üzerinden ölçülür.
  • Sonuç durum çubuğunda canlı gösterilir: $(zap) Reply N saved tokens · $(shield) K redacted

MCP Araçları

optimize_context

Verilen metin veya kodu budar; sonuç ve token tasarruf özetini döndürür.

read_file_optimized

Çalışma alanındaki dosyayı okur ve optimize edilmiş içeriği döndürür.

get_token_stats

Tüm pencerelerdeki birikimli çağrı sayısını ve token/kredi tasarrufunu verir.

Optimizasyon Motoru

  • Yalnızca bütün satırı kaplayan yorumları siler (dile göre: C-benzeri // ve /* */, # tabanlı); string içindeki yorum benzeri metne dokunmaz.
  • Satır sonu boşluklarını siler, ardışık boş satırları teke indirir.
  • Tekrar eden ardışık satırları yalnızca log ve plaintext için katlar: satır (x3); koda ve veriye dokunmaz.
  • conservative: anlamı değiştirmez. aggressive: ek olarak yalnızca plaintext içinde çoklu boşlukları tek boşluğa indirir.

Telemetri ve Kullanıcı Deneyimi

  • Her çağrıda ham ve optimize token sayıları ölçülür, stats.json dosyasına kilit altında atomik yazılır (tmp + rename).
  • Eklenti dosyayı izler; durum çubuğu anında güncellenir. Tüm VS Code pencereleri aynı birikimli toplamı gösterir.
  • Net kazanç, yanıtın tamamı (kısa özet satırı dahil) üzerinden ölçülür; çok küçük dosyalarda net değer negatif olabilir.
  • AI Token Optimizer: Show Token Savings komutu birikimli raporu gösterir.

Güvenlik

  • read_file_optimized yalnızca çalışma alanı kökü içindeki dosyaları okur.
  • Kök dışına çıkan yollar (.., mutlak yollar) ve dışarıyı gösteren symlink'ler reddedilir.
  • Çalışma alanı yapılandırılmamışsa dosya okuma tamamen kapalıdır.
  • Gizli anahtarlar, e-posta, IP ve MAC adresleri modele ulaşmadan maskelenir.
  • Araçlar readOnlyHint ile salt-okunur olarak işaretlidir.

Sınırlar ve Yol Haritası

  • Optimizasyon yalnızca MCP araç çıktısı seviyesinde çalışır; VS Code, Copilot'un kendi prompt'unu yeniden yazmaya izin vermez.
  • İstatistikler tüm pencereler için birikimlidir ve global storage altında tutulur.
  • Tekrar eden satırların katlanması için languageId değeri log veya plaintext verilmelidir.
  • Olası geliştirmeler: daha fazla dil desteği, minify/özetleme stratejileri, oturum geçmişi grafikleri.
